# CONTRIBUTING

Just a quick note for now, All contributions big and small are welcome. We don't have a code style or preferred language but as long as the language that is used can import lit it is allowed. All changes to the source at the end of each month will be pushed to the npm repository so if you plan on using this library in production use the code in this repository.

---

# Notes

If you do push changes, please leave your name or GitHub username and a link to your GitHub to the CONTRIBUTERS.md file as listed in the format below

```md
- example [my-github](https://github.com/my-github)
```
